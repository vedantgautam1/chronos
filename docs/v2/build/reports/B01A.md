# B01A — canonical.py: dict keys validated like values; the fingerprint made deterministic

**In plain words:** Chronos v2's fingerprint — the helper that turns any piece of
data into a stable hash so later builds can ask "have we seen this before?" — now
treats dictionary *keys* as carefully as it always treated dictionary *values*.
Before this build, a key that wasn't plain text was silently squashed into text,
and for one kind of key (an unknown object) that text contained the object's memory
address, so the very same data produced a different fingerprint every time it was
run. That would have let a repeat trial look like a fresh one — the exact
self-deception the fingerprint exists to stop. Now a non-string key is refused at
once with a clear error, so a fingerprint is guaranteed to mean the same thing every
time. This closes the single defect the B01 review found, and nothing else changes.
