# B01 — v2 project scaffold, core helpers, automatic tests

**In plain words:** Chronos v2 now has its own home inside the repository, fully
separate from the frozen v1 code. It is a fresh Python 3.14 project called
`chronos2`, with two small helpers every later build will reuse — one that
enforces the time rules (everything in UTC, half-open ranges) and one that
turns any piece of data into a stable fingerprint — plus a test suite, and a
GitHub Actions pipeline that runs those tests automatically, with its own
Postgres database, on every change. Nothing here touches or imports v1.
